# Organisation logos

Drop organisation logo files into this folder. The homepage marquee discovers
them automatically at build time.

Supported formats: `.svg`, `.png`, `.jpg`, `.jpeg`, `.webp`, and `.avif`.

Use short, descriptive filenames such as `research-england.svg`; the filename
is converted into the accessible organisation name. Remove
`placeholder-organisation.svg` after adding real logos, then rebuild or redeploy
the site.
